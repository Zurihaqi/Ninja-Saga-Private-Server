# Legacy text protocol codec

Bounded Engine.IO protocol 3 text polling and Socket.IO protocol 4 text packets. Protocol 4 here means the legacy Socket.IO wire revision used by Socket.IO 2.x, not the Socket.IO 4.x library version.

Supports all seven Engine.IO text packet markers and polling batches with JavaScript UTF-16 length prefixes. Socket.IO supports namespace connect/disconnect and JSON events. It rejects acknowledgement IDs, binary attachments, error packets and connect payloads. Payload bytes, packet bytes and batch counts have independent limits. JSON deserialization uses Serde's recursion limit; encoding rejects excessive caller-built nesting and uses a bounded writer.

`tests/fixtures/engine-v3.json` is generated by engine.io-parser 2.2.1, installed through the pinned Socket.IO 2.5.0 development client. Run `node tests/compatibility/socket-client/generate-fixtures.cjs` from the workspace root to regenerate it. The fixture covers ping, namespace connect, Unicode including a surrogate pair, JSON event data, and close. Rust tests check byte identity and malformed framing. These are generated test packets, not Flash captures.

Protocol references: [Engine.IO revision 3](https://github.com/socketio/engine.io-protocol/tree/v3), [Socket.IO revision 4](https://github.com/socketio/socket.io-protocol/tree/v4).
