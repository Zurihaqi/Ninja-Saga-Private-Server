# Headless gameplay regression

Run `./scripts/test-gameplay.ps1` from the configured Windows workspace. It provisions minimal fixtures in `ninja_ci_test`, never launches or controls the game window, and never targets the playable database. The original-catalog mode imports into separate `ninja_ci_reference_test`. The local helper uses ignored MySQL credentials; CI uses its disposable service database.

The Rust test sends real AMF3 envelopes through the Axum gateway and verifies MySQL changes. It covers accounts, actual AIR creation nesting/hash, character/battle data, equipment, points, leveling, mission rewards and duplicate completion, session rotation, shops, normal/advanced academy, skill presets, all four exams and concurrent promotion claims, pet ownership/rename/release/mission XP, paid NPC recruitment and mission consumption, forging/material rollback, consumable consumption, talent discovery/upgrades/reset, Sage Mode and class changes. It creates a uniquely named synthetic account and deletes it on success. Failed runs may leave their synthetic account for diagnosis. Existing player accounts are not modified.

Use `./scripts/test-gameplay.ps1 -ReferenceCatalog` to run with the original catalog export and JSON. The expanded suite also covers hunting/markets, daily/pet villa, friends/mail/Shadow War, event/admin/HTTP flows, animation ownership, pet food/learning, and authorization rejection. Test code is in `apps/game-server/src/lib.rs`, `src/tests/extension.rs` and `src/tests/player_actions.rs`.

`mission.json` is the minimal mission-definition subset required by the test, derived from the pinned `public/game_data/mission.json` entry `msn_1`. It is deliberately independent of downloaded SWF assets. The test uses enemy statistics and rewards from the test database.

Set `BOOTSTRAP_GAMEPLAY_TEST_DB=1` only with dedicated `ninja_ci_test` or `ninja_ci_reference_test`. Bootstrap creates the original schema, additive migrations and synthetic fixtures. Extended tests change global event/configuration data, so do not run them against a live playable or production database. Both helpers enforce dedicated targets. Hosted CI runs the same AMF/persistence assertions; rendering, damage animations and complete event/multiplayer behavior remain actual-client checks.

The client-contract regression also checks floating-point Upgrade Max, second Secret rank gates, all preset prices, Pet Villa movie aliases/training limits, exact REST membership flows, shipped Christmas battle/minigame/gacha payloads, and free-product claim replay protection. Chat/PvP workspace tests open real loopback WebSockets independently of the game window.
